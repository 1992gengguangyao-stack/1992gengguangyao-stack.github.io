Get RizzKey running in under a minute.

Setup

  1. Open RizzKey → Settings → tap a provider chip (OpenAI, DeepSeek, Groq…) → paste your API key → Test connection.
  2. iPhone Settings → General → Keyboard → Keyboards → Add New Keyboard → RizzKey.
  3. Tap RizzKey in the keyboard list and enable Full Access (needed for AI replies).
  4. In any chat: copy her last message, tap ✨ Reply on the keyboard, pick your favorite reply.

Common questions

  • AI replies are locked / show a lock icon — either no API key (RizzKey → Settings) or Full Access is off (iPhone Settings → Keyboards → RizzKey).
  • "401 unauthorized" — your API key and Base URL must be from the same provider.
  • No context appears — copy her message in the chat app first, then open the Reply panel; or tap Paste inside the panel.
  • Which providers work? — any OpenAI-compatible API. Get a key from OpenAI, DeepSeek, Groq or OpenRouter.
